Avocado Co. – Augmented Reality Product Experience

About the Project :
An interactive Augmented Reality (AR) experience that displays a 3D avocado model using a Hiro marker. Users can interact with virtual objects and explore the product through their camera.

Technologies Used :
   HTML
   A-Frame
   AR.js
   JavaScript
   Web-based Augmented Reality
